# Codebase safety and resource review

Reviewer `codex/safety-01`. Independent first pass completed 2026-11-19 at 20:46 UTC. Reviewed the working tree at `d1cdefc`, including the local DAgger and guided-search code. Claude's review was unavailable and was not opened during this pass.

## Summary

The highest-priority issues are process ownership during forced cleanup, the bridge's reliance on an unverified external firewall rule, and memory limits that may never be checked while a search is stuck. The repository also has identifiable paths for resource exhaustion and for losing bot save or telemetry data. No active damage to the user's machine or data was established. This review used source inspection, existing measurements, and offline tests. It used no game slot, made no security-setting changes, and did not run failure scenarios against the live bridge.

## Coverage and verification

- Reviewed the launcher, native build and source, Windows paths and isolation, hook/thread lifecycle, checkpoint bookkeeping, protocol framing and client, save tools, resource controls, and game-slot supervisor. The launcher verifies the executable hash before resuming. Remote pipe clients are rejected, and control work is queued to the game frame. SEH protects some reads but does not establish that a readable pointer is still the intended live object. No specific use-after-free or missing native allocation owner was established in this static pass.
- Reviewed the Python environment, replay and policy workflow, drills and online loaders, M3–M7 study and search code, and telemetry and attempt ledgers. Demonstration batch loading closes each archive and uses one archive at a time. DAgger and evaluation traces retain one rollout and can raise peak memory, but the examined production paths have configured tick or evaluation limits.
- Reviewed both dashboard paths, nightly publishing, local log retention, and code handling network inputs and credentials. The Site renders queue content as text. Its nightly snapshot is intentionally public on GitHub even though the Site is private, so only intended public fields belong in that export. No private credential or Defender-setting change was identified by the targeted source scan. The repository's PowerShell execution-policy overrides are per-process. No host Defender, firewall, or scheduled-task settings were modified or verified.
- The offline test suite passed all 69 tests. No live process termination, network transfer, save edit, or game-slot launch was used to validate these scenarios.
